# سینما۵۰۰ — نسخهٔ مستقل

۵۰۰ اثر IMDb، تم شب و روز، جست‌وجوی نام/رتبه/سال، ثبت تماشا، لیست تماشا، محبوب‌ها، امتیاز شخصی، پیشنهاد امشب و آمار.

## انتشار رایگان در GitHub Pages

این پوشه آمادهٔ انتشار است و به نصب یا build نیاز ندارد. محتویاتش را در ریشهٔ یک مخزن عمومی قرار دهید. سپس Settings → Pages → Deploy from a branch → main → /(root) → Save را انتخاب کنید.

## اطلاعات شخصی

داده‌ها فقط در localStorage مرورگر ذخیره می‌شوند. حساب ابری و همگام‌سازی خودکار وجود ندارد. در «دفتر من» خروجی JSON بگیرید و روی دستگاه یا دامنهٔ جدید وارد کنید. اطلاعات فعلی هنگام ورود پشتیبان اولویت دارند. پاک‌کردن داده‌های مرورگر بدون پشتیبان باعث ازدست‌رفتن دفتر می‌شود.

فهرست و رتبه‌ها ثابت و متعلق به تاریخ درج‌شده در سایت‌اند. catalogue.js حاوی ۲۵۰ فیلم و ۲۵۰ سریال است. برای نسخهٔ تازه باید داده‌ها و تصاویر را جایگزین کنید. هیچ API پولی لازم نیست. میزبانی رایگان تابع شرایط و محدودیت‌های GitHub است و تضمین مادام‌العمر ندارد.

منابع داده و پوستر: IMDb، Cinemeta/Metahub، quantavil/imdb-dataset و alae-touba/imdb-rest-api. تصاویر و نام‌ها متعلق به صاحبان حقوق آثارند. وابستگی رسمی به IMDb وجود ندارد.

## توضیحات فارسی و ورود گوگل

تمام ۴۰۳ خلاصهٔ موجود در فهرست به فارسی بازنویسی شده‌اند؛ ۹۷ اثر در دادهٔ اولیه خلاصه نداشته‌اند. متن‌ها داخل خود catalogue.js هستند و به API ترجمه نیازی ندارند.

ورود گوگل با Supabase Auth آمادهٔ اتصال است و به‌صورت پیش‌فرض تا تنظیم پروژه غیرفعال می‌ماند. راهنمای [GOOGLE-LOGIN.md](./GOOGLE-LOGIN.md) را ببینید. دفتر هر هویت محلی و مجزا است؛ همگام‌سازی ابری اضافه نشده است. SDK نسخهٔ 2.118.0 فقط پس از فعال‌شدن تنظیمات ورود بارگذاری می‌شود.
